# RPG 2.0 SP1 — 1막 「노라의 밤」 리마스터 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1막을 줄거리 변경 없이 밀도 5배로 — 굳은 주민 20·컷신 8·마수 보스 리메이크·2막 복선. 스펙: `docs/superpowers/specs/2026-07-28-rpg2-sp1-act1-design.md` (조사 카탈로그·컷신 표·보스 설계 원본 — 각 태스크는 스펙 해당 섹션을 정본으로 삼는다).

**Architecture:** SP0 기반(cutsceneSlice/CutsceneController·보스 phases/gimmick·tint·zonePhenomena) 첫 실전 적용. 프레임워크 확장은 2건뿐(StoryTriggers `cutscene` 필드, ModelAvatar `paused`) — 나머지는 전부 데이터·저작.

**Tech Stack:** 기존과 동일. 검증: ts-node + puppeteer 헤드리스(qa-lib, 기본 3010).

## Global Constraints

- tsc ≤ 26 유지(증가 금지). eslint 신규 0 — 슬라이스·게이트 관례 any 예외(플랜 SP0 명문화 조항 승계).
- 신규 좌표 전수 착지 검증: `__navFindWalkable` 스냅 드리프트 ≤1.2m + 기존 상호작용점 3.5m+ + 로머 캠프 8m+ 이격(ts-node 감사 스크립트 — QA 스윕 방법 재사용).
- 세이브: 신규 플래그만(`frozen_*`, `phen_port`, `story_cs_*`). 스테이지·기존 플래그·좌표 무변경. 구세이브는 진행 지점부터 신규 콘텐츠 접근.
- SP0 저작 규약: battle 스텝 뒤 연출은 승패 불문 재생 / battle 뒤 camReset 지양 / gimmick.every ≥ 1 / 보스 스킬은 적 전용 신설 / 던전 라이트 합산 관리(이번 SP 해당 없음).
- 대사 톤: 로티(감성·요리 비유), 테오(분석·"흥미롭네요"), 아린(절제·군인체). 기존 대사와 존댓말 체계 일치(테오만 존댓말).
- 커밋: main 직행, 한국어 `[feat]/[fix]`, 태스크당 1커밋(+리뷰 수정 커밋 허용).
- 헤드리스 규약(qa-lib): enterGame 기본 3010, 대사 소거 루프, 방어 튜토리얼 플래그 선주입됨, ~9fps 대기 여유, 컷신 스크린샷은 rAF 내 drawImage(`sp0-t8b-visual.js` 기법).
