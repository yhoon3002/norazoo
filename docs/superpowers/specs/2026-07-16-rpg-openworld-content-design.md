# RPG 오픈월드 콘텐츠 확장 — 설계

날짜: 2026-07-16
상태: 승인됨 (사용자: "전부 넣어줘 + 튜토리얼은 짧은 거리에 끝내야")

## 배경 / 문제

- 맵은 넓은데 콘텐츠가 길잡이 트레일 위에만 있어 정해진 루트로만 진행하는 느낌.
- 튜토리얼(스폰→광장)이 81m 도보라 초반이 늘어짐.

## 결정 사항 (사용자 확인 완료)

4개 방향 전부 + 튜토리얼 압축. 구현 순서: 압축 → 필드 라이프 → POI → 사이드 퀘스트 → 낚시.

## 0. 튜토리얼 압축

- 스폰을 마을 어귀(93.3,-29.4) → 광장 초입(28,-24)으로 이동 — 요리사까지 ~20m.
- `TRAIL_TOWN`을 광장 초입→광장 구간(6포인트)만 남김. 해방된 어귀~광장 길은 자유 탐험 지역이 되어 아래 콘텐츠를 배치.
- 기존 세이브는 저장된 좌표 유지(영향 없음).

## C. 필드 라이프

- **리스폰 시스템**: 새 `fieldSlice` — `fieldRespawn: Record<key, ms>` (비영속, 세이브 제외). key는 리스폰 시 지울 플래그들을 `|`로 연결한 문자열. `RespawnController`(필드 컴포넌트)가 1초 주기로 만료 타이머를 소거하고 플래그를 되살림.
- **배회 몬스터 5무리**(r1~r5): 길 밖 초원/외곽 배치, `FIELD_ENEMIES`에 `respawn?: number`(ms) 추가, 3분 리스폰. 기존 wander AI 재사용.
- **레어 드롭**: 신규 재료 `monster_core`(마물 결정, 판매 45G) — orc/mage 템플릿 드롭 테이블에 chance 0.15 추가.
- **채집물 리스폰**: 기존 채집물 전부 3분 리스폰 (`FieldGatherable`에 `respawnMs` prop).
- **황금 약초**: `golden_herb`(판매 60G). 후보 3곳 중 필드 진입마다 랜덤 1곳 스폰, 3분 리스폰.

## A. 탐험 보상 POI

- **전망 포인트 3곳**(`poiData.ts` + `FieldPoi.tsx`): 부두 끝·바람 언덕 초입·동쪽 해안. 반경 3m 접근 시 자동 발견 — 팝업 배너 + 골드/경험치(파티 전원), `flags[poi_${id}]`.
- **숨은 보물 6개**(t11~t16): 기존 FieldTreasure 시스템 재사용, 길 밖 숲/외곽 지상에 배치 (FieldTreasure는 데이터 y를 그대로 사용하므로 높이 미확인 지붕은 배제). t14에는 소년 퀘스트용 "연"(kite) 아이템.
- **지도 연동**: 미발견 POI/숨은 보물은 25m 이내 접근 시 미니맵에 "?" 표시. 발견한 전망 포인트는 전체지도에 아이콘 영구 표시.

## B. 사이드 퀘스트 NPC 3명

`COOK_QUEST` 패턴을 `SIDE_QUESTS` 배열(`questData.ts`)로 일반화: {npc(위치/모델/라벨), availableFrom(stage), 수락/진행/완료 대사, needs(아이템) 또는 kills(fieldId), rewards+골드}. `FieldQuestNpc.tsx`가 렌더+상태 머신(수락→진행→완료), 머리 위 ❗ 마커, 미니맵/전체지도 ❗ 표시.

1. **파수꾼**(성문 경비, VikingHelmet, ch2~): "외곽 정리" — 전용 무리(bounty_1, 리스폰 없음) 처치 → 골드+물약. (시계탑 종이 닿지 않는 성문 밖이라 화를 면했다는 설정 대사)
2. **견습 대장장이**(Viking_Female, ch3~): "마물 결정" — monster_core 2 + slime_gel 2 납품 → power_ring + 골드.
3. **깨어난 소년**(Cowboy_Hair, ch4~ — 로어 각성과 연결): "잃어버린 연" — 지붕 보물 t14의 kite 전달 → 골드+회복 물약. 어부 퀘스트(낚시 연계)는 D 참조.
4. **어부**(Elf, ch3~, 항구): "물고기 3마리" — fish_common 3 납품 → mana_crystal 2 + 골드.

## D. 미니게임 — 항구 낚시

- 부두 낚시터(`FishingSpot.tsx`) E → 낚시 오버레이(`FishingPanel.tsx`, `ui.fishingOpen`): 좌우로 움직이는 마커를 초록 존에서 Space로 3회 히트 — 정확도에 따라 `fish_common`(생선, 18G)/`fish_rare`(월광어, 90G) 획득.
- 낚시 중 이동 잠금·오버레이 배타 규칙은 전체지도와 동일하게 적용.

## 테스트 / 검증

- tsc 에러 수 기준선(28) 유지. 브라우저 검증은 사용자 최종 확인: 새 스폰 위치, 배회 몬스터 조우/리스폰, 채집물 리스폰, POI 발견 배너와 "?" 마커, 퀘스트 3종 수락~완료, 낚시 획득.

## 비범위 (YAGNI)

- 퀘스트 로그 UI(플래그로만 추적), 낚시 물고기 도감, 배회 몬스터 스폰 웨이브, 지하 POI(지오메트리 미확인), 동물 NPC.
