# RPG: 캐릭터 재정의 + 대사 화자 구분 + 파티 동행 + 지도 시스템 — 설계

날짜: 2026-07-16
상태: 승인됨

## 배경 / 문제

1. 파티 캐릭터 이름(Gustave/Maëlle/Sciel)이 '클레르 옵스퀴르: 33 원정대' 캐릭터와 동일 — 표절 인상, 세계관과 무관.
2. 대사 시 화자 이름만 노란 텍스트로 표시되어 누가 말하는지 구분 불가. 필드에는 활성 캐릭터 1명만 렌더링되어 나머지 파티원은 화면에 존재하지도 않음.
3. 지도가 없음 — 맵이 넓어(마을 x≈0 → 항구 x≈218, 언덕 z≈-210) 목표 비콘만으로는 길찾기 답답.

## 결정 사항 (사용자 확인 완료)

- 이름 교체 + 역할/성격/말투 재정의 (오마주 유지 아님)
- 화자 구분: 대화 박스 초상화 + 캐릭터 고유색 + 필드의 말하는 캐릭터 머리 위 하이라이트
- 파티원 3명 모두 필드에 렌더링 (동료 따라다니기)
- 지도: 미니맵(HUD 상시) + 전체지도(M키), 전체지도에서 깃발 클릭 빠른이동
- 지도 이미지: 3D 환경 탑다운 오쏘그래픽 1회 베이크 (실패 시 폴백: 손그림 SVG 지도)

## 1. 캐릭터 리네이밍 + 역할 재정의

### 새 캐릭터

| 기존 | 새 id | 새 이름 | 역할 | 성격/말투 | 고유색 | 초상화 |
|---|---|---|---|---|---|---|
| gustave | `arin` | 아린 | 왕도 조사대 대장, 여성 기사 | 짧고 단호, 책임감. 감정 절제 | 파랑 (#6EA8FE 계열) | 🗡️ |
| maelle | `theo` | 테오 | 태엽학자 겸 마법사, 시계탑 전문가 | 수다스러운 존댓말, 지적 호기심 | 보라 (#B58CF6 계열) | 🔮 |
| sciel | `lotti` | 로티 | 견습 요리사 출신 검사, 막내 | 밝고 직설적, 먹을 것에 진심 | 초록 (#7BD88F 계열) | 🍳 |

- 로티의 모델이 실제로 `Chef_Hat.fbx` — "요리사 견습생" 설정과 일치. 스토리의 요리사 NPC와 사제 관계로 엮어 대사 재미 요소로 활용.
- 스킬/스탯/장비/모델은 기존 구성 유지 (이름·정체성만 교체).

### 데이터 구조

- `gameData.ts`에 `PARTY_META: Record<CharId, { displayName, color, portrait, role, speechStyle }>` 단일 소스 추가. UI(대화 박스, 배틀 UI, 메뉴)가 전부 이 메타를 참조.
- `DEFAULT_PARTY`의 `id`/`name` 교체 (gustave→arin, maelle→theo, sciel→lotti).
- NPC 화자 메타(요리사 👨‍🍳, 일지/쪽지 📜, 굳은 주민 🗿 등)는 별도 `NPC_SPEAKERS` 테이블. 매칭 실패 시 중립 호박색 + 기본 아이콘.

### 대사 리라이팅

- `storyData.ts` 전체 대사(스토리 트리거, 로어 포인트, 각성 대사)와 `FieldMerchant.tsx` 대사를 새 성격·말투에 맞게 리라이팅.
- `DialogueLine`에 `speakerId?: CharId` 추가. 파티원 대사는 speakerId 기반, NPC는 기존 `speaker` 표시명 유지.

### 세이브 호환

- SaveV1에 party 객체가 통째로 저장되어 있어 옛 이름이 박제됨.
- 로드 시 마이그레이션: id 매핑(gustave→arin, maelle→theo, sciel→lotti)으로 각 파티원의 `id`/`name`/`portrait`/`modelUrl`을 새 메타로 덮어씀. 스탯/경험치/장비는 보존.

## 2. 대사 UI 개선 (DialogueUI)

- 대화 박스 왼쪽에 초상화 카드: 캐릭터 고유색 그라데이션 배경 + 초상화 이모지 크게.
- 화자 이름과 박스 테두리를 캐릭터 고유색으로 틴트. NPC는 중립 호박색 유지 + NPC 아이콘.
- 진행 방식(Space/Enter/클릭)은 기존 그대로.

## 3. 파티 동행 + 화자 하이라이트

### FieldCompanions (신규 컴포넌트)

- 비활성 파티원 2명이 리더 뒤를 따라다님.
- 팔로우 로직: 리더 이동 궤적을 브레드크럼(일정 거리 간격 포인트 큐)으로 기록, 동료들은 각자 고정 오프셋 거리의 궤적 지점을 향해 이동. 지면 스냅은 기존 ground-height 훅(`useEnvironmentGroundHeight`) 재사용.
- 렌더링/애니메이션: `ModelAvatar` 재사용, 이동 속도에 따라 걷기/대기 애니메이션 전환.
- 전투 진입/캐릭터 교체/빠른이동 시 리더 위치로 재배치(워프).

### 화자 하이라이트

- 대사 진행 중 현재 라인의 `speakerId`가 필드에 존재하는 개체(파티원 3명 또는 상인 NPC)면 머리 위에 고유색 마커(통통 튀는 ▼ + 소프트 글로우) 표시.
- 필드에 없는 화자(일지, 쪽지 등)는 마커 생략 — 대화 박스 초상화만으로 구분.

## 4. 지도 시스템

### 탑다운 베이크

- 환경 모델 로드 완료 후 1회: 오쏘그래픽 카메라를 맵 상공에 배치해 WebGL 렌더타겟(≈2048px)에 촬영 → 지도 텍스처로 보관.
- 월드 경계는 환경 메시 바운딩박스에서 자동 계산. 월드좌표(x,z) ↔ 지도UV 변환 유틸 제공.
- 다층 지형(지붕/지하)은 v1에서 탑다운 그대로 수용 (지붕이 보이는 형태).
- 베이크 실패/품질 미달 시 폴백: 랜드마크 중심 손그림 SVG 지도로 교체 가능하도록 지도 텍스처 소스를 추상화.

### 미니맵 (HUD)

- 화면 우상단 원형(~160px), 북쪽 고정.
- 마커: 플레이어(방향 화살표), 현재 목표 지점, 체크포인트 깃발, 상인.
- 대화/전투/메뉴 중에는 숨김.

### 전체지도 (M키)

- M키 토글 오버레이, ESC로 닫기. 기존 메뉴 UI 스타일과 통일.
- 베이크 텍스처 전체 표시 + 마커: 체크포인트 깃발, 현재 목표, 플레이어 위치, 상인, 로어 포인트.
- 깃발 클릭 → 빠른이동 (기존 FastTravelPanel/storySlice 로직 재사용, 활성화된 깃발만).
- 범례 표시.

## 구현 순서

1. 캐릭터 메타/리네이밍 + 세이브 마이그레이션 (다른 작업의 기반)
2. 대사 UI 개선
3. 파티 동행 + 화자 하이라이트
4. 지도 시스템 (베이크 → 미니맵 → 전체지도 → 빠른이동 연동)

## 테스트 / 검증

- 기존 세이브 로드 → 새 이름/모델로 마이그레이션되고 스탯·진행도 보존 확인.
- 스토리 프롤로그~ch4 대사 전 구간에서 초상화/색상/하이라이트 정상 표시.
- 동료가 계단/경사/다층 지형에서 리더를 따라오고, 전투·빠른이동 후 재배치 확인.
- 미니맵/전체지도 마커 위치가 실제 월드 좌표와 일치(마을 광장·항구·언덕 깃발 기준). M키/ESC 토글, 깃발 클릭 빠른이동 동작.
- 빌드: 기존 lint/TS 에러 42개 기준으로 회귀 없음 확인 (에러 수 비교).

## 비범위 (YAGNI)

- 실시간 미니맵 카메라 렌더링, 지도 팬/줌, 층별 지도 전환, 초상화 일러스트(이모지 카드로 충분), 동료 개별 조작.
