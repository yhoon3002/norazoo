# RPG 종장 — 스토리 완결 + 몬스터 다양화 + 존 정복 보상 설계

날짜: 2026-07-20
상태: 승인됨 (사용자: 배 진입 / 소·강아지 포함 전부 활용 / 탐사 기반 존 완료)

## 1. 스토리 완결 (ch4 마무리 → ch5 어둠의 협곡 → 엔딩)

### 무대 실측 (완료)
남동 군도 = **어둠의 협곡** 존: 내부 도보 네트워크 22,274셀 (X 103~289, Z 1~220), 본토(-33)보다 10m 낮은 저지대(-42~-44). 핵심 좌표(도달 검증 완료): 상륙지 (139.5, -42.25, 17.5) · 보스 공터 (268.5, -43.25, 42.5) · 제단 최고점 (141.5, -25.25, 73.5).

### 진행 흐름
1. **ch4_hill 완결 — 제단 수호전**: 바람 언덕 제단(0,-210) 도착 트리거 → 대사 → **수호 무리 전투 강제 진입**(orc_chief+orc×2) → 승리 시 두 번째 태엽 조각 획득 대사 → 스테이지 `ch5_gorge`, 목표 "항구의 사공을 찾아가자"(target 항구).
2. **사공/배 진입**: 항구 부두에 사공 NPC(ch5_gorge부터, Elf 모델 어부와 구분되는 위치) — E → 확인 대사 → 협곡 상륙지로 텔레포트 + ChapterTitle "종장 — 어둠의 협곡". 상륙지에 귀환용 사공 배치(E → 항구 귀환). 상륙지 깃발(빠른이동 편입).
3. **협곡 탐험**: gorge 존 콘텐츠(채집 8·배회 5무리·보물 3·전망=제단) + 전용 몬스터(태엽 병정·어둠 마수).
4. **최종 보스전**: 보스 공터 접근 트리거 → 대사 → **태엽을 삼킨 마수**(보스, 대형 스케일) + 태엽 병정×2 전투 → 승리 시 세 번째 조각 → 목표 "노라로 돌아가 시계탑을 깨우자".
5. **엔딩**: 시계탑 앞(마을, tower_note 부근 24.5,-17) 도착 트리거 → 엔딩 시퀀스: ChapterTitle "종막 — 시계탑이 깨어나다" + 파티/요리사 대사 + **주민 전원 각성**(모든 lore 석상 awake, 스테이지 `epilogue`) + 대형 보상(3000G + 황금 약초 3 + monster_core 5) → **포스트게임**: 목표 "되살아난 노라를 자유롭게 여행하자"(target null), 의뢰·채집·리스폰·존 정복 전부 계속.
- STAGE_ORDER: `... , "ch4_hill", "ch5_gorge", "epilogue"`. 진행 플래그: `story_ch4_guardians_done`(수호전 승리), `story_boss_done`(보스 승리).

## 2. 몬스터 다양화 — 신규 8종 + 무리 확대

| 템플릿 | 모델 | 컨셉/패턴 | 주 출몰 |
|---|---|---|---|
| ghoul 구울 | Zombie_Female | 빠른 좀비, 2연타 | 서부·남부 |
| mad_bull 미친 들소 | Cow | 돌진 2연타(비패리 1타) | 언덕·남부 초원 |

- `ENEMY_TEMPLATES`에 `scale?: number` 추가(보스 2.4), 전투 렌더(EnemyMesh/필드 아바타)가 반영.
- **zoneContent roamerPacks 존당 4~6조합**으로 확대(신규 종 혼합 — 예: 마을 [슬라임,들개], [들개×3]; 언덕 [들소,오크], [오크족장,오크]…), 배회 스폰 증설: 본토 +10무리(존별 +2, hill/north_woods는 후보 소진으로 기존 유지) + 협곡 5무리 = **총 31무리**.
- 신규 드롭: 협곡 특산 `dark_crystal`(어둠 수정, 판매 90G) — 협곡 몬스터/채집.

## 3. 존 정복 보상

- **기준(존당 5요소, 전부 기존 플래그로 판정)**: 깃발 활성 + 숨은 보물 3개 + 전망 포인트 발견.
- 달성 시 1회: `zone_done_${zoneId}` 플래그 + 팝업 "🏆 {존} 정복!" + 보상(티어별 골드 300~1000 + 존 특산 패키지) — `ZONE_REWARDS` 테이블.
- `ZoneCompletionController`(필드, 스로틀 체크). **전체지도 존 라벨에 진행도(n/5, 완료 시 🏆)** 표시. 협곡 포함 8존 전부 적용.

## 신규 아이템
`dark_crystal` 어둠 수정 90G (MATERIALS/ITEM_PRICES 등록).

## 검증
tsc ≤ 28(현재 27) + 헤드리스: 사공 텔레포트 상륙/귀환, ch4→ch5→ch5 보스→엔딩 상태 전이 시뮬레이션(플래그·스테이지), 존 정복 트리거. 잔여는 사용자 플레이.

## 비범위
보스 다단 페이즈 전환, 컷신 카메라 연출, 사운드, 엔딩 크레딧 롤, 2회차(뉴게임+).
