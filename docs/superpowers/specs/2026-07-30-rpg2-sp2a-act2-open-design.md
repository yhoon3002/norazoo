# RPG 2.0 SP2a — 2막 개막: 항구·바람 언덕 존 챕터 설계

## 배경/목표

마스터 스펙의 2막 「여덟 개의 멈춘 시간」 첫 묶음. 1막 에필로그(시계탑 복구·마을 재건) 이후 **시간 이상이 대륙에서 연쇄 재발**하는 2막을 열고, 존 챕터 2개(항구·바람 언덕)와 마을 막간①, 동료 서사(아린·로티) 개시, 레벨 커브 확장을 담는다. 분량 목표 ~2.5h. SP0 4계 시스템 + SP1 확장(트리거 cutscene/setFlags·FrozenVillager) 위에서 **신규 프레임워크 없이 데이터·저작 중심**으로 구현한다.

**전제**: 기존 세이브 호환(STAGE_ORDER 뒤 append·신규 플래그만). 에필로그 완료 세이브가 자연스럽게 2막 진입. SP1 누적 저작 규약 전부 준수.

---

## ① 구조 — 스테이지·플로우

`STAGE_ORDER` 뒤에 append: `act2_intro` → `act2_port` → `act2_hill` (SP2b에서 계속).

- **진입**: 에필로그 상태에서 광장 접근 시 막간① 컷신(`cs_act2_omen`) — 되살아난 시계탑이 한 박자 헛도는 징조 + 항구발 전갈("파도가 다시 멈췄소") → `act2_intro`→`act2_port` 전이, 목표=항구.
- **항구 챕터 완료** → 언덕발 전갈(양치기의 편지 — "같은 아침이 계속 온다") → `act2_hill`.
- **언덕 챕터 완료** → 막간 브리지 대사(다음 이상 징후 — SP2b 예고) 후 SP2a 종료. `act2_hill` 완료 플래그가 SP2b 진입점.

구세이브: 에필로그 세이브 로드 → cs_act2_omen 트리거가 광장 반경에서 발동(신규 플래그라 미발동 상태). 1막 미완 세이브는 기존 흐름 그대로(2막 트리거들은 stage 게이트로 잠김).

## ② 항구 챕터 「멈춘 파도」 재발 (~60분)

1막 finale에서 꺼진 `phen_port`가 **강화판으로 재점화**(`phen_port2` — 기존 현상 데이터 대비 포그 짙게·파티클 증량, ZONE_PHENOMENA 항목 추가. 두 플래그 공존 시 phen_port2 우선).

- **조사 아크(트리거 체인 4비트)**: 부두 도착(재발 현장 컷신 `cs_port2_arrival` — 얼어붙은 파도 위 정지한 갈매기 연출) → 깨어난 주민 증언 2곳(1막 f_porter·f_sailor가 **각성 상태로 증언** — FrozenVillager awake 대사를 act2 분기로 확장: `awake2?: DialogueLine[]` 필드, act2_port부터 우선 표시) → 수상한 소용돌이 발견(부두 끝).
- **미니 던전 「침수 창고」**: 부두 창고 구획 — 던전 프레임워크 재사용(신규 DungeonDef `port_warehouse`: 항구층(-38) 하부 실측 개척, 게이트 1쌍·문/스위치 2개·조명 프로파일 청록). 좌표 전부 이원 검증.
- **존 보스 「파도를 삼킨 자」(`wave_devourer`)**: ghoul 모델 변형(스케일 1.6·청록 틴트) 신규 템플릿, Lv 13. 2페이즈(70% 격노·30% 침수 — 틴트 심화+scaleMul 1.15) + 카운트다운 기믹 `tide_swallow`(매 3턴, 단일 강타+freeze 1턴). 적 전용 스킬 3종 신설(wave_snap/wave_spray/tide_swallow — 단일 대상, T4 마수 산식 준용: 보스→파티 3턴 사이클 출력을 마수 대비 +10~15%로 설정).
- **태엽 유물 ①**: 보스 격파 → 유물 회수 컷신(`cs_port2_relic` — 파도가 풀리는 연출: phen_port2 소등 set 스텝) + 항구 시간 복구.
- **아린 서사 1장(`cs_arin_letter`)**: 부두에서 왕도 전령과 조우 — 기사단이 "대륙 시간 이상"을 이미 알고 있었다는 봉인 서신. 아린의 갈등 개시(직접 명명 없이 "그분" 흔적과 교차). 유대 에피소드가 아니라 메인 트리거 체인 내 컷신.

## ③ 바람 언덕 챕터 「반복되는 하루」 (~60분)

- **현상**: `phen_hill` — ZONE_PHENOMENA 신규(호박색 여명 고정: dirIntensity 하향+주황 앰비언트+정지 민들레 파티클). 목장 주민들이 하루가 리셋됨을 모른 채 같은 아침을 산다.
- **조사 아크(4비트)**: 언덕 도착 컷신(`cs_hill2_arrival` — 같은 뱃고동... 아니, 같은 양 울음이 반복) → 양치기 증언(1막 f_shepherd 각성체 awake2 — "어제 기억이 나질 않아") → 반복의 진원(제단 뒤 목장) → 은둔자의 힌트(f_hermit awake2 — "찻물이 매일 아침 같은 온도야").
- **미니 던전 「제단 지하」**: hill 층 하부 실측 개척(`hill_undercroft`) — 게이트 1쌍·문/스위치 2개·조명 호박색.
- **존 보스 「새벽을 삼킨 자」(`dawn_devourer`)**: mad_bull 모델 변형(스케일 1.5·호박 틴트), Lv 14. 2페이즈 + 기믹 `dawn_swallow`(매 3턴, 단일 강타+stun 1턴). 적 전용 스킬 3종(마수 산식 준용, 항구 보스 대비 +5~10%).
- **태엽 유물 ②** + 언덕 시간 복구(`cs_hill2_relic` — 여명이 마침내 아침으로 넘어가는 연출: phen_hill 소등).
- **로티 서사 1장(`cs_lotti_home`)**: 목장이 요리사 사부의 고향 — 사부가 남긴 낡은 조리 노트 발견("장인과 함께 먹던 스튜" — 공방 장인 복선 교차). 로티의 요리 비유가 처음으로 아픈 데를 건드리는 톤.

## ④ 마을 막간① + 동료 서사 연결

- `cs_act2_omen`(§① 진입 컷신): 시계탑 헛도는 소리 → 파티 3인 반응 → 전갈. 재건된 광장(깨어난 주민들)이 배경 — 1막 보상의 시각적 재확인.
- 아린·로티 서사는 각 존 체인에 편입(위 §②③). 테오 서사는 SP2b(숲·수변) 배정 — 이번엔 조연 반응만.
- 항구·언덕 챕터 완료 시 마을 요리사에게 귀환 보고 대사 각 1비트(선택 방문 — 트리거 아닌 FieldMerchant 대사 분기, stage 게이트).

## ⑤ 레벨 커브 확장

- 현행: 파티 Lv5 시작·1막 종료 ~Lv12·스킬 unlockLevel 최고 12·1막 보스 Lv15.
- 2막 몬스터: 존 로머 팩 티어 상향은 하지 않음(기존 존 밸런스 유지 — 라운드A 커브 존중). 신규 보스 2기(Lv13·14)와 던전 내 정예 팩 2종(기존 몬스터 Lv+2 변형 템플릿, 던전 한정 배치)만 추가.
- 스킬: 파티 3인 각 1종 신규(unlockLevel 14 — 아린 방어기·테오 광역기·로티 지원기, 기존 QTE 플랜 재사용). TTK 시뮬(양방향 ±10% 게이트 — SP1 규약)로 수치 확정.
- expToNext 커브는 무변경(기존 커브가 Lv15+까지 유효한지 확인만 — 부족 시 연장).

## ⑥ 구현 원칙·검증 계약

- 프레임워크 신규 0. 확장 2건만: FrozenVillager `awake2`(act2 분기 대사 — optional·구세이브 무해), ZONE_PHENOMENA 다중 플래그 우선순위(phen_port2 > phen_port — 배열 순서로 해결 가능하면 데이터만).
- 컷신 9종(omen·port2 3·hill2 3·arin·lotti), 신규 트리거 체인 act2 ~10개, 던전 2·보스 2·정예 2·스킬 3·유물 플래그 2.
- 좌표 전부 이원 검증 + 배치 감사 위반 0. 카메라는 SP1 워크플로(walkable 앵커·수평 시선·확정 샷 보관).
- 검증 계약: ① 에필로그 세이브 → 2막 전체 주행(막간①→항구→언덕→브리지) 실경로 ② 두 현상 점등/소등과 던전 왕복 ③ 보스 2기 페이즈+기믹+TTK 게이트 ④ awake2 분기(1막 상태·2막 상태 각각) ⑤ 1막 회귀(sp1 배터리 전체) + sp0 스모크 ⑥ tsc ≤26·드로우콜 ≤500·구세이브(에필로그·1막 중반) 2종 호환.
- 분량: 태스크당 커밋 1 + 리뷰 수정 관행 유지. 헤드리스 규약은 SP1 누적본.
