# RPG 2.0 SP1 — 1막 「노라의 밤」 리마스터 설계

## 배경/목표

마스터 스펙(2026-07-27-rpg-2.0-remake-design.md)의 SP1. 현행 1막(프롤로그~협곡~에필로그, 대사 비트 ~15개)을 **줄거리 변경 없이** 밀도 5배로 리마스터한다: 조사 이벤트 20개 + 컷신 8개 + 협곡 보스 리메이크 + 2막 복선. SP0 기반(컷신·보스·존 현상·틴트) 첫 실전 적용.

**전제**: 기존 스테이지·트리거·세이브 완전 호환(신규 플래그만 추가). 구세이브는 진행 지점부터 신규 콘텐츠를 자연스럽게 만난다. tsc ≤26, 신규 좌표 착지 검증, SP0 저작 규약 5조 준수.

---

## ① 굳은 주민 조사 이벤트 20개 — 「멈춘 사람들」

**시스템**: 신규 `FrozenVillager` 컴포넌트 1개 + `FROZEN_VILLAGERS` 데이터(data/frozenData.ts).
- 비주얼: ModelAvatar **정지 상태**(애니메이션 미재생) + 청회색 틴트(`#8fa8b8`, SP0 틴트 시스템 재사용) — "시간에 갇힌 사람".
- 상호작용: E 조사 → 대사 2~3줄(사연) → `frozen_${id}` 플래그 + 최초 1회 소액 보상(일부만) + 도감 killCounts `frozen_seen` 카운트.
- 에필로그(시계탑 복구) 후: 같은 위치에서 깨어난 모습(틴트 해제·idle 애니) + 감사 대사 1줄로 교체 — 복구의 정서적 보상.
- 모델은 기존 FBX 15종 로테이션(주민별 지정).

**카탈로그** (위치는 구현 시 착지 검증, 사연은 저작 시 확장 — 한 줄 스케치):

## ② 컷신 8개

SP0 컷신 시스템 사용. 트리거 연결을 위해 `STORY_TRIGGERS`에 `cutscene?: string` 필드 추가(발동 시 dialogue 대신 startCutscene — 소폭 프레임워크 확장). 저작 규약: battle 스텝 뒤 연출은 승패 불문 재생·battle 뒤 camReset 지양.

| id | 트리거 시점 | 구성 비트 |
|---|---|---|
| cs_opening | 프롤로그 시작(신규 게임) | 멈춘 거리 카메라 팬 → 파티 3인 도입 대사(기존 3줄 확장) → 시계탑 원경 |
| cs_cook_meet | 요리사 첫 대화 | 광장 화덕 줌 → 요리사-로티 재회(기존 대사 유지+확장) → 태엽 조각 3개 설명 |
| cs_first_battle | 튜토리얼 전투 승리 후 | 슬라임 잔해에서 태엽 부스러기 발견 — 테오 "자연 발생이 아니에요" |
| cs_port_arrival | 항구 진입 | **phen_port 활성**(멈춘 파도 첫 가동) → 부두 팬 → 파티 대사 → 일지 발견 |
| cs_lighthouse | 등대 일지 조사 | 일지 클로즈업 연출 — 확장된 일지 3편 낭독(협곡 불빛·"태엽을 삼키는 것"·**"그분이 오셨다"**) |
| cs_altar_guardian | 제단 전투 트리거 | 제단 카메라 상승 → 수호자 등장 연출 → battle(기존 수호자) → 조각 획득 |
| cs_gorge_descent | 협곡 진입 | 어둠 속 카메라 → 파티 긴장 대사 → 원경에 마수 실루엣(스케일 연출) |
| cs_maw_finale | 마수 격파 후 | 마수 유언 "…그분의 시간은, 되돌아온다" → 조각 공명 → (귀환 후) 시계탑 복구 — 마을이 깨어나는 팬(주민 틴트 해제와 동기) |

phen_port는 cs_port_arrival에서 켜고 에필로그(시계탑 복구)에 끄는 것이 1막 서사: "항구의 시간도 돌아왔다". (2막에서 재발 — SP2a.)

## ③ 협곡 보스 리메이크 — 「태엽을 삼킨 마수」

기존 ch5 전투를 SP0 보스 프레임워크로 재구축. `ENEMY_TEMPLATES.clockwork_maw` 신설(기존 마수 템플릿 대체·수치는 현 밸런스 커브 유지 — 레벨 ~12, HP는 현행 보스 기준 ±10%).

- **적 전용 스킬 신설**(규약 ④, 전부 단일 대상): `maw_snap`(강타·기본), `maw_gear_spray`(중타+debuff_def), `maw_time_bite`(대기술 — 카운트다운 강제 스킬, 고데미지+stun 1턴).
- **페이즈**: P1(기본) → P2(70%: 격노 — 틴트 적동색·aiPattern smart·gear_spray 해금·announce) → P3(30%: 폭주 — 틴트 보라·scaleMul 1.15·시간 가속 연출 announce).
- **기믹**: countdown every 3 → `maw_time_bite`(경고 "⏳ 태엽이 울린다"). 스턴으로 지연 가능(SP0 확정 카운터플레이) — 전투 중 힌트 팝업 1회.
- 격파 → cs_maw_finale. 기존 defeated_ 플래그·재도전 경로 유지.

## ④ 기타 확장

- **등대지기 일지**: 기존 1편 → 3편(cs_lighthouse에서 낭독 + 이후 등대에서 재열람 가능한 LorePoint 1개 추가).
- **요리사 대사 씨앗**: 화덕 퀘스트 대사에 "옛날 공방 장인이 시계탑을 만들었지" 1줄 삽입(f_toymaker 연결).
- **스테이지 전환 대사 확장**: 기존 STORY_TRIGGERS의 dialogue를 평균 2배(3줄→5~6줄)로 — 이동 동기·감정 비트 보강. 줄거리·목표·좌표 무변경.

## ⑤ 구현 원칙·검증 계약

- 프레임워크 확장 최소: StoryTriggers `cutscene` 필드 1건 + FrozenVillager 컴포넌트 1건. 그 외 전부 데이터·저작.
- 조사 이벤트 좌표 20 + LorePoint 1: 착지 검증 파이프라인(스냅 드리프트 ≤1.2m·기존 스팟 3.5m+·로머 캠프 8m+) 전수 통과 필수.
- 검증 계약(헤드리스): ① 신규 게임 → 8컷신 전부 순서대로 발동·완주(스킵 경로 포함) ② 조사 이벤트 20개 E 전수(플래그·카운트) ③ 보스 3페이즈+기믹 전이 ④ 에필로그 후 주민 각성 상태 전환 ⑤ 구세이브(에필로그 시점) 로드 → 신규 콘텐츠 접근 가능 ⑥ 기존 QA 스모크 회귀.
- 분량 목표: 1막 통산 플레이 ~2.5h(현행 ~1h + 조사·컷신·확장 대사).
