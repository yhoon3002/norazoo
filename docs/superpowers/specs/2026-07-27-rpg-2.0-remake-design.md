# RPG 2.0 리메이크 — 「멈춘 시간」 3막 대서사

## 배경/목표

현행 콘텐츠는 시스템(전투·경제 10종·도감·투기장)은 풍부하나 서사가 얇다 — 메인 스토리 9스테이지에 대사 비트 ~15개·목표 11개, 플레이 약 2시간. 이를 소규모 라운드 추가가 아니라 **15시간+ 본격 JRPG 규모의 대서사로 리메이크**한다.

**확정 전제** (사용자 승인):
- 목표 볼륨 **15시간+** (메인+서브 합산).
- **기존 에셋 재활용** — 맵(Environment.glb)·캐릭터 FBX 15종 고정. 신규 보스/몹은 색·스케일·이펙트 변형, 신규 지역은 미사용 지하 수로층·지붕·기존 존 재활용. 코드만으로 완결.
- 서사 프레임 **A안 「멈춘 시간」**: 기존 로어(시계탑·태엽 조각·태엽을 삼킨 마수·시간 테마 적 스킬)를 대서사의 1막으로 흡수.
- 기존 세이브 호환 유지(신규 필드 전부 optional, STAGE_ORDER 뒤에 append).

---

## ① 서사 골격 — 3막

**세계 설정 확장**: 노라의 시계탑은 대륙의 시간을 지탱하는 탑들 중 하나. 협곡의 마수는 시작일 뿐 — 배후의 존재가 "태엽을 삼키는 자"들을 풀고 있다.

### 1막 「노라의 밤」 (현행 리마스터, ~2.5h)
- 줄거리 유지: 태엽 조각 3개 회수(항구 등대 → 언덕 제단 → 협곡) → 마수 격파 → 시계탑 복구.
- 확장: 굳은 주민 조사 이벤트 ~20개(각자의 멈춘 사연 — 세계관 빌드업), 등대지기 일지 확장(배후 복선), 마수의 유언("…그분의 시간은, 되돌아온다"), 챕터 컷신 8개, 협곡 보스전을 신규 보스 프레임워크로 리메이크.

### 2막 「여덟 개의 멈춘 시간」 (~8h, 몸통)
시계탑 복구 후에도 대륙 곳곳에서 시간 이상 연쇄 발생. 존별 챕터:

| 존 | 시간 이상 현상 | 비고 |
|---|---|---|
| 동부 항구 | 멈춘 파도, 반복되는 뱃고동 | 아린 서사 |
| 바람 언덕 | 하루가 리셋되는 목장 | 로티 서사 |
| 서부 대삼림 | 계절이 뒤엉킨 숲 | 테오 서사 |
| 북부 숲길 | 시간이 거꾸로 흐르는 길 | 빌런 복선 |
| 북동 수변 | 물이 하늘로 흐르는 수로 | 테오 서사 |
| 남부 해안 | 지지 않는 노을 | 아린 서사 |
| 어둠의 협곡 | 마수 사후 벌어진 시간의 상처 | 정체 공개 |
| 노라 마을 | 막간 거점(재건과 새 위협) | 막간 ①② |

각 존 챕터 = 이상 현상 연출 + 조사 아크 퀘스트 + 미니 던전(지하·지붕·기존 지형) + 존 보스 **"삼킨 자"**(기존 몬스터 변형 + 시간 기믹) + 태엽 유물 회수 + 동료 개인 서사(로티: 요리사 사부의 과거 / 아린: 왕도 기사단이 재앙을 알고도 침묵한 이유 / 테오: 에테르 학자 시절 스승의 행방).

**빌런 — 첫 태엽장인**: 시계탑들을 세운 장본인. 잃은 딸의 시간을 되감으려다 실패, 대륙 전체를 "그날"로 되돌리려 한다. 삼킨 자들은 그의 회수꾼. 2막 후반(협곡 재방문)에 정체 공개되는 슬픈 빌런.

### 3막 「시계탑 태엽부」 (~3h)
미사용 **지하 수로층 전체** = 대륙 시계탑들의 태엽을 잇는 지하 태엽 미궁. 다층 던전·퍼즐 → 태엽장인 대면(설득/전투 분기 연출) → 멀티 페이즈 최종전 → 진엔딩(되감을 것인가, 흐르게 할 것인가).

## ② 서브프로젝트 분해 (각각 독립 스펙→플랜→구현→검증)

| SP | 내용 | 산출 |
|---|---|---|
| **SP0** | 연출·전투 기반 공사 | 컷신/이벤트 시스템·보스 프레임워크·던전 프레임워크·존 현상 툴킷 |
| **SP1** | 1막 리마스터 | 조사 이벤트 ~20·대사 밀도 5배·컷신 8·협곡 보스 리메이크·복선 |
| **SP2a** | 2막: 항구+바람 언덕+마을 막간① | 존 챕터 2 + 아린·로티 서사 개시 + 레벨 커브 확장 선반영 |
| **SP2b** | 2막: 대삼림+숲길+수변 | 존 챕터 3 + 테오 서사 + 빌런 복선 |
| **SP2c** | 2막: 남부 해안+협곡 재방문+막간② | 존 챕터 2 + 빌런 정체 공개 + 3막 개방 |
| **SP3** | 3막 태엽부 대미궁 | 지하층 개척·다층 퍼즐·분기 연출·최종전·진엔딩 |
| **SP4** | 성장·엔드게임 | 스킬트리/장비 세트 심화·NG+·보스 러시·15h 밸런스 최종 패스 |

**순서**: SP0 → SP1 → SP2a → SP2b → SP2c → SP3 → SP4.
레벨 캡·스킬 습득 커브 확장은 SP2a에 선반영(2막 진행에 필요), 심화(트리·세트)만 SP4.

### SP0 상세 범위 (다음 플랜 대상)
1. **컷신/이벤트 시스템**: `cutsceneSlice` + 필드 `CutsceneController`. 시퀀스 데이터 = 대사·카메라 지시(포커스 대상/이동/줌/유지시간)·이펙트·캐릭터 애니 지시의 타임라인. 기존 dialogue UI 재사용(확장). 이벤트 전투 트리거(고정 배치·승패 후속 시퀀스). 스킵(홀드) 지원. 스토리 데이터 파일에 선언적 정의.
2. **보스 프레임워크**: `ENEMY_TEMPLATES` 확장 — `phases[]`(HP 임계 전이·페이즈별 스킬셋/패턴/연출)·`gimmicks[]`(카운트다운 QTE·행동 되감기 등 시간 기믹). 비주얼 변형(색 틴트·스케일·발광)은 ModelAvatar 파라미터. 보스 UI(페이즈 게이지·기믹 경고).
3. **던전 프레임워크**: 던전 데이터(게이트 좌표·조명 프로파일·문/스위치/퍼즐 플래그) + `DungeonController`. 지하층 조명은 InteriorLighting 확장. 미니맵/전체지도 지하 대응(층 필터).
4. **존 현상 툴킷**: `ZONE_PHENOMENA` 데이터 + 존 진입 감지 컨트롤러 — 조명·포그·파티클·앰비언트 오버라이드(현상 해소 시 원복). 예: 노을 고정(라이트 색), 역행(파티클 역재생), 멈춘 파도(수면 셰이더 정지).

## ③ 아키텍처 원칙

- **스토리 확장**: `STAGE_ORDER` 뒤에 `act2_*`·`act3_*` append — `stageAtLeast`가 순서 기반이라 기존 게이트(에필로그 NPC 등) 무손상. 기존 에필로그는 "1막 에필로그"로 재해석되어 2막 진입점이 된다.
- **세이브 호환**: 신규 세이브 필드 전부 optional + applySave 기본값. 구세이브는 1막 완료 상태로 자연 진입.
- **배치 규약**: 신규 좌표는 전부 헤드리스 착지 검증(navFindWalkable 스냅 드리프트 ≤1.2m + 텔레포트 착지) + 로머 캠프 8m 이격 감사 통과 필수(QA 스윕 파이프라인 재활용).
- **성능 예산**: 필드 드로우콜 ≤500 유지(현재 160). 신규 상시 useFrame 금지 — 컨트롤러는 스로틀/이벤트 구동. BVH·베이크 분산 빌드 위에 얹는 신규 로딩은 동일 분산 패턴.
- **검증**: SP마다 헤드리스 배터리(qa-lib) + 스토리 진행 시뮬(스테이지 순차 주입·컷신 스킵 경로) + 기존 QA 스윕 회귀.

## ④ 리스크

- **분량 리스크**: 15h는 대사·퀘스트 데이터 작성량이 지배 — SP 단위로 완결 배포해 중간에 멈춰도 게임이 성립하도록 설계(각 SP 종료 = 플레이 가능 상태).
- **연출 표현력 한계**: 에셋 고정이라 현상 표현이 조명/포그/파티클/이벤트에 의존 — SP0에서 툴킷 프로토타입으로 존 1개(항구) 현상을 선검증.
- **밸런스**: 레벨 커브 확장은 기존 TTK 시뮬 방식(밸런스 라운드 선례) 재사용.
